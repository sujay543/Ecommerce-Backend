# Ecommerce Backend API

A production-ready REST API for an eCommerce platform built with Node.js, Express, and MongoDB.

## 🚀 Live API

https://ecommerce-backend-ulhb.onrender.com

## Tech Stack

* Node.js
* Express.js
* MongoDB (Mongoose)
* JWT Authentication
* REST API

## Features

* User authentication (signup/login)
* Product management
* Cart management
* Order management
* Secure API with JWT
* Error handling middleware

## API Endpoints

### Authentication

POST /api/v1/users/signup
POST /api/v1/users/login

### Products

GET /api/v1/products

### Orders

POST /api/v1/orders
GET /api/v1/orders

## Installation

```bash
git clone https://github.com/sujay543/Ecommerce-Backend.git
cd Ecommerce-Backend
npm install
npm start
```
